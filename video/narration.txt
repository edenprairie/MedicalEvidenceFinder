This is the live Medical Evidence Finder prototype. We start with a candidate on an index page, marked as unverified. A business user previews a correction, confirms the exact page and quote, and saves the lesson with a reason. The next search uses the corrected substantive passage and highlights the source span. Now the business editor changes a reusable agent skill, records the author and reason, and publishes a new version. The application detects the changed markdown and uses it on the next request without restarting Python. Production keeps the previous approved version immutable in the registry. If the new behavior causes a regression, an administrator can activate the previous approved version as a rollback. The current implementation is a framework-neutral adapter, ready to connect to a hosted LLM wiki or prompt registry.
