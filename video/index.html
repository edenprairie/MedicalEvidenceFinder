05 / WHAT THE AGENT USES

Three separate layers

Markdown skill

Reusable behavior: how to rank sections, validate anchors, and abstain.

Structured memory

Confirmed user corrections, scope, provenance, confidence, and revocation.

Source evidence

PDF text and coordinates that must be validated independently.

TAKEAWAY

Framework-neutral today. LLM-wiki compatible tomorrow.

The current implementation is a local adapter, not a third-party LLM wiki product. A hosted wiki or prompt registry can replace the markdown and SQLite adapters while preserving the retrieval, validation, and version-assignment contracts.
